# 喵喵知識站

貓咪日常照護與行為觀察入門網站，使用原生 HTML/CSS，可直接部署到 GitHub Pages。

## 網站頁面
- `index.html`：首頁與分類入口
- `pages/care.html`：日常照護
- `pages/behavior.html`：行為觀察
- `pages/about.html`：關於本站

新增頁面前請先閱讀 [AGENTS.md](AGENTS.md)，並依照其中的頁面、風格、命名及內容規則開發。

## 本機預覽
直接用瀏覽器開啟 `index.html`。

## GitHub Pages
將整個專案上傳至 GitHub Repository，進入 Settings → Pages，選擇 Deploy from a branch，Branch 選 `main`、資料夾選 `/ (root)` 後儲存。部署完成後即可使用 GitHub Pages 提供的網址。
